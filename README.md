Excel Data Cleaner

A Python tool that automatically cleans messy Excel datasets.

Features

- Remove duplicate records
- Remove completely empty rows
- Clean column names and text values
- Handle missing data
- Generate cleaning reports
- Export cleaned Excel files

Technologies

- Python
- Pandas
- OpenPyXL
- Google Colab

Use Cases

Useful for businesses, freelancers, and individuals who work with Excel spreadsheets and need clean, organized data.
